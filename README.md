# javascript-racingcar-precourse

## 기능 목록

1️⃣ 입력 및 출력

- Console 모듈을 활용하여 입력(readLine)과 출력(print) 기능을 구현

2️⃣ 자동차 생성 및 유효성 검사

- Car 객체 생성
- 이름이 공백 혹은 5자 초과일 경우 에러 처리

3️⃣ 경주 게임 실행 로직

- 라운드 횟수가 양의 정수가 아닐 경우 에러 처리
- 각 라운드 별 Random 값으로 전진 및 정지 처리

4️⃣ 경주 게임 로깅

- 각 라운드 이후 각 자동차의 이동 결과 로깅

5️⃣ 경주 게임 우승자 계산

- 가장 많이 이동한 자동차들의 이름을 반환

6️⃣ 결과 출력

- 실행 로그와 우승자로 요구된 포맷에 맞게 출력

7️⃣ 각 기능 목록에 대한 테스팅

- Jest를 이용하여 기능 단위별 테스트 수행
